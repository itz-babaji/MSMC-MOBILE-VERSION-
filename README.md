# 🎮 MSMC-MOBILE-VERSION

**MSMC Mobile Version** is a mobile-focused **Minecraft account checker** built around Microsoft/Hotmail authentication workflows.

> ⚠️ **For authorized checking/scraping.**.

## ✨ Features

* 🎮 Minecraft account Checker
* 📧 Microsoft / Hotmail authentication support
* 📱 Mobile & Termux friendly
* ⚡ Lightweight CLI workflow
* 🛠️ Simple setup and configuration
* 🐧 Linux / Ubuntu / VPS compatible
* 🔐 Designed for authorized account 

## 🚀 Get Started

### 1. Clone

```bash
git clone https://github.com/itz-babaji/MSMC-MOBILE-VERSION.git
cd MSMC-MOBILE-VERSION
```

### 2. Check Project Files

```bash
ls -la
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

For a cleaner Python environment:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 4. Run

Check the repository's entry-point files and run the documented launcher, for example:

```bash
python3 main.py
```

## 📱 Termux

On Termux, make sure Python and Git are installed:

```bash
pkg update
pkg install git python
```

Then:

```bash
git clone https://github.com/itz-babaji/MSMC-MOBILE-VERSION.git
cd MSMC-MOBILE-VERSION
pip install -r requirements.txt
```

## 🧩 Requirements
